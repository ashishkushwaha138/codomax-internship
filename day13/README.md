## 📊 Dataset Description

The dataset (`student_scores.csv`) contains student study hours and exam scores:
- **Study Hours**: Number of hours studied
- **Exam Score**: Score obtained in exam (target variable)

The cleaned dataset (`student_scores_cleaned.csv`) has been processed for:
- Missing value handling
- Duplicate removal
- Outlier treatment

## 📓 Notebooks Overview

1. **01_data_exploration.ipynb** - Data loading, basic statistics, and initial EDA
2. **02_data_cleaning.ipynb** - Data cleaning pipeline implementation
3. **03_visualization.ipynb** - Matplotlib & Seaborn visualizations
4. **04_model_training.ipynb** - Linear regression model building
5. **05_model_evaluation.ipynb** - Model evaluation with MAE, MSE, R² metrics
