# Internship Project - Machine Learning Journey

A comprehensive 12-day machine learning internship project covering Python basics, NumPy, Pandas, Data Visualization, Data Cleaning, and Machine Learning with Scikit-learn.

## 🚀 Quick Start

```bash
# Install dependencies
pip install numpy pandas matplotlib scikit-learn jupyter

# Run prediction app
python day11/prediction_app.py

# Start Jupyter
jupyter notebook day12/notebooks/
```

## 📚 Learning Path

| Day | Topic | Key Concepts |
|-----|-------|--------------|
| 1-2 | Python Basics | Variables, loops, functions |
| 3 | NumPy | Arrays, operations, indexing |
| 4 | Pandas | DataFrames, CSV, exploration |
| 5 | Data Cleaning | Missing values, duplicates |
| 6 | Visualization | Matplotlib, Seaborn, EDA |
| 7 | ML Basics | Train/test split, regression |
| 8 | Linear Regression | Model building, saving |
| 9 | Predictions | Score prediction |
| 10 | Evaluation | MAE, MSE, R² |
| 11 | App | Interactive prediction |
| 12 | Polish | Notebooks, docs, structure |
